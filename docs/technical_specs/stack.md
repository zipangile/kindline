# Technical Specifications

## Frontend & Backend
- **Framework:** Next.js (App Router preferred)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Components:** Radix UI / Shadcn UI

## Mobile
- **Framework:** Flutter (Cross-platform iOS and Android)

## Authentication
- **Provider:** Clerk (Modern, secure, and easy-to-implement auth)

## Payments
The following payment gateways will be integrated:
1. **Flutterwave:** For pan-African and international payments.
2. **DPO (Direct Pay Online):** For secure credit card and mobile money processing.
3. **Lenco by BroadPay:** Specifically for localized Zambian payment processing and business banking integration.

## Database & Storage
- **Database:** PostgreSQL (Suggested for Next.js/Vercel compatibility)
- **Storage:** AWS S3 or Supabase Storage for assets and field photography.
